# A 股"异动"规则速查（2026-11 整理）

"异动"在 A 股语境里有两层意思，做预警功能时必须分开：

1. **交易所监管口径**：交易所交易规则里的"异常波动 / 严重异常波动"，按收盘价算，日级别，触发后公司要公告、可能停牌核查。
2. **盘中行情口径**：行情软件（短线精灵 / 盘口异动）里的"火箭发射、大笔买入、封涨停"等，按逐笔/分时数据算，秒级到分钟级，没有统一标准，各家自定阈值。

---

## 一、交易所口径：异常波动（日级别）

### 1. 核心指标：收盘价涨跌幅偏离值

- 单日：偏离值 = 个股涨跌幅 − 对应基准指数涨跌幅。触及涨跌停的，按涨跌幅限制比例计。
- 累计（N 日）：`(期末收盘价/期初前收盘价 − 1) − (指数期末收盘点/期初前收盘点 − 1)`，期间有除权除息要复权。
- 基准指数（深交所规则原文；上交所对应）：
  - 深市主板 A 股：深证 A 股指数（399107）
  - 创业板：创业板综合指数（399102）
  - 沪市主板：上证 A 股指数（999998 / 000002）
  - 科创板：科创 50（000688）
  - 北交所：由北交所公告（市场普遍按北证 50，需核实）

### 2. 异常波动认定标准（满足其一）

| 板块 | 连续 3 日偏离值累计 | 换手率条件 | 条款 |
|---|---|---|---|
| 沪/深主板 | ±20% | 3 日日均换手 ÷ 前 5 日日均换手 ≥ 30 倍，且 3 日累计换手 ≥ 20% | 沪 5.4.2 / 深 5.4.3 |
| 主板 ST / *ST | ±12% | 同上 | 同上 |
| 创业板 | ±30% | 无换手率条件 | 深 5.4.3 |
| 科创板 | ±30% | — | 沪 6.1.10 |
| 北交所 | **最近 3 个有成交的交易日**内 ±40%（最长回溯 20 个交易日，"有成交"仅指竞价成交） | — | 北 5.4.2 |

注意：
- 无涨跌幅限制的股票（新股上市前 5 日等）不纳入异常波动/严重异常波动计算（深 5.4.5）。
- 退市整理期股票不纳入（深 4.5.7）。
- 异常波动公布后，指标从**次一交易日或复牌之日**起重新计算（深 5.4.5）。这意味着一只股票触发后要"清零重算"，不是滑动窗口一直叠加。
- 用真实公告校准后的实现口径（见 README）："N 日内"包含更短的子窗口；严重异常波动的三条线各自独立清零；个股与指数涨幅各自保留到 0.01% 再相减。

### 3. 严重异常波动认定标准（满足其一）

| 情形 | 主板 | 创业板 / 科创板 |
|---|---|---|
| 连续 10 日内出现同向异常波动次数 | 4 次 | 3 次 |
| 连续 10 日偏离值累计 | +100% / −50% | 同 |
| 连续 30 日偏离值累计 | +200% / −70% | 同 |

条款：沪 5.4.3 / 6.1.11，深 5.4.4。北交所交易规则中未查到对应量化标准（2026-04 上市规则修订新增了严重异常波动监管安排，需查原文）。

### 4. 触发后的后果

- 异常波动：公司次一交易日开盘前披露异常波动公告，通常不停牌；交易所公布期间买卖金额最大 5 家营业部。
- 严重异常波动：公司核查并公告，交易所可要求停牌核查、公布投资者分类交易统计、加强监控、要求券商向客户提示风险；该股进入**重点监控名单（后续 10 个交易日）**，期间任意 1 分钟内单向申报达"巨量"（一般股票 ≥100 万股或 ≥1000 万元）即属申报速率异常，可能被暂停账户交易（2025-08 上纬新材案例）。

### 5. 相关日级别阈值：龙虎榜（公开交易信息）

| 指标 | 主板 | 创业板 / 科创板 |
|---|---|---|
| 当日收盘价涨跌幅偏离值 | ±7%（各前 5） | 涨跌幅 ±15%（前 5） |
| 当日振幅 (最高−最低)/最低 | 15% | 30% |
| 当日换手率 | 20% | 30% |

另：连续 3 日偏离值累计达标也上榜（即异常波动榜）。

### 6. 盘中临时停牌（无涨跌幅限制股票）

盘中成交价较当日开盘价首次涨/跌达 30%、60% 各停 10 分钟；跨 14:57 的于 14:57 复牌。（沪 4.2.4 / 深 4.3.4）

### 7. 涨跌幅限制（算"封板"要用）

主板 10%，主板风险警示 5%，退市整理 10%，创业板/科创板 20%（含其风险警示股），北交所 30%，新股上市前 5 日（北交所首日）不限。

## 二、交易所口径：异常交易行为（账户级，主要用于合规提示）

《沪深主板股票异常交易实时监控细则》（2023-02 发布）五大类 14 条，与"预警"相关的量化阈值：

- "大量"：一般股票 ≥30 万股或 ≥300 万元；"巨量"：≥100 万股或 ≥1000 万元；"高比例" ≥30%；"多次" ≥3 次。
- 拉抬打压：连续竞价**任意 3 分钟**内，成交量大、占比高且股价涨跌 ≥4%（上证 50 成份股 ≥2%）；收盘集合竞价 ≥3%（上证 50 ≥2%）。
- 虚假申报：开盘集合竞价偏离前收 5%（风险警示股 3%）以上大量申报且撤单 ≥50%。
- 维持涨跌停价格：涨跌停剩余巨量申报占比高、持续 ≥10 分钟、当日成交 <70%。
- 程序化交易（2025-07-07 起）：单账户每秒申报/撤单 ≥300 笔或单日 ≥20000 笔认定为高频。

这些是针对单个账户的，做全市场行情预警用不上，但"3 分钟涨 4%"这种口径可以借用作盘中阈值。

## 三、行情软件口径：盘中异动（短线精灵 / 盘口异动）

无官方标准。大智慧/同花顺/东方财富的常见类别及典型判定逻辑：

| 类别 | 项目 | 典型判定 |
|---|---|---|
| 股价异动 | 火箭发射 | 5 分钟内快速上涨并创当日新高 |
| | 快速反弹 | 下跌后 5 分钟快速上涨 |
| | 高台跳水 | 上涨后 5 分钟快速下跌 |
| | 加速下跌 | 下跌中再 5 分钟快速下跌 |
| 成交异动 | 大笔买入 / 大笔卖出 | 单笔主动买/卖成交量大（旧版：单笔换手 >0.1%，或 ≥50 万股 / ≥100 万元） |
| 盘口异动 | 有大买盘 / 有大卖盘 | 买/卖 5 档合计挂单大（旧版：>80 万股且占流通盘 >1%） |
| 涨跌停 | 封涨停 / 封跌停 / 打开涨停 / 打开跌停 | 本笔成交触及/离开涨跌停价 |
| 竞价 | 竞价上涨 / 竞价下跌 | 集合竞价匹配价较前收偏离达阈值 |
| 缺口/均线 | 高开 5 日线、低开 5 日线、向上缺口、向下缺口 | 开盘价与 5 日均线 / 昨日高低点的关系 |
| 新高新低 | 60 日新高 / 新低、60 日大幅上涨 / 下跌 | 价格突破 60 日极值 |
| 指数/板块 | 拉升指数、打压指数、板块放量、板块快速涨跌 | 对指数点位的贡献、板块指数 5 分钟涨幅、量比 |
