# yd-win · A 股异动空间

盘中实时计算每只股票距离"严重异常波动"还剩多少空间，手机网页查看。

- **异动池**：自动整理近期频繁异动的沪深 A 股，按剩余空间从小到大排序。
- **搜索**：按代码、名称、拼音查任意一只沪深 A 股。
- 每只票给出：今日触发价与空间、今日涨停是否触线、明日空间、连板第几板触线、三条线的当前偏离值、是否处于重点监控期。

## 运行

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

手机浏览器打开 `http://服务器IP:8000/`。Python 3.9 及以上即可。服务没有登录保护，建议放在 nginx 后面加访问控制，或只开放给自己的 IP。

systemd 示例（路径按实际修改）：

```ini
[Unit]
Description=yd-win
After=network-online.target

[Service]
WorkingDirectory=/opt/yd-win
ExecStart=/opt/yd-win/.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

## 计算口径

规则原文摘要见 `docs/a股异动规则.md`。引擎在 `app/engine.py`，要点：

- 偏离值累计 = 个股区间涨幅 − 同期基准指数涨幅。基准：沪主板上证 A 股指数、深主板深证 A 指、创业板创业板综指、科创板科创 50。
- 严重异常波动三条线：10 日偏离 +100%、30 日偏离 +200%、10 日内同向异常波动 4 次（创业板和科创板 3 次）。
- "N 个交易日内"包含更短的子窗口。
- 三条线各自独立，哪条触发哪条从次日清零重算；普通异常波动触发后 3 日窗口清零。
- 个股和指数涨幅各自保留到 0.01% 再相减。
- 新股前 5 个交易日不计入。今日除权除息的票按前收盘价自动校正。

以上口径用五个真实公告回测过，触发日期与次数全部一致：上纬新材（2025-07）、品茗科技（2025-09）、ST京蓝（2026-02）、爱丽家居（2026-07）、深中华A（2026-09）。复现：

```bash
python scripts/calibrate.py sh688585 2025-07-08 2025-07-30
python tests/test_engine.py
```

## 数据

- **实时报价、排行、搜索**：腾讯行情接口，服务端转发。盘中每 5 分钟用全市场排行的 N 日涨幅粗筛候选。
- **日线**：存在 `data/yd.db`（SQLite）。每天收盘定稿后用实时报价把当日收盘价追加入库，平时不请求日线接口。
- **需要拉日线时**（首次启动、新入池、除权、断档）：走全局限速队列，默认每秒一只，可用环境变量 `YD_FETCH_INTERVAL` 调整。腾讯被拦截时自动切到新浪，15 分钟后再试腾讯。新浪数据不复权，腾讯恢复后后台自动替换。
- **首次启动**：两百多只候选约需 4 分钟补完，期间列表逐步出现。搜索的票会插队优先拉取。之后重启直接从磁盘读取。

入池门槛和限速参数在 `app/service.py` 顶部：`POOL_DEV10`、`POOL_DEV30`、`POOL_COUNT`、`FETCH_INTERVAL`。

## 页面

- 按最先会触碰的那条线分成两组：**10日线**（含 10 日偏离 +100% 与异动次数线）和 **30日线**。
- 每张卡片列出偏离值算式：个股涨幅 − 基准指数涨幅 = 偏离，并标明基准日。
- 每张卡片有未来 5 个交易日的"触线需涨"，展开后是完整 10 个交易日的触发线表，列出每天 10 日线、30 日线、异动次数线各自的触发价。
- 逐日推演假设股价和指数都停在当前位置：窗口每后移一天，早期低价基准移出，触发价随之抬高。触发涨幅为当天相对前收，今日用实际前收，之后用现价。
- 交易日历在 `app/tradecal.py`，已录入 2027 年休市安排。每年 11 月国务院公布次年节假日后需要补充。
- 网址加 `#g30` 直接打开 30 日组。

## 已知限制

- 不含北交所：腾讯没有北交所历史日线，且北交所没有公开的严重异常波动量化标准。
- 未实现主板"换手率 30 倍"那条普通异常波动，实际很少触发。
- 历史上的异常波动次数是引擎按行情推算的，不读取公告。停牌核查、交易所酌情认定等情况可能造成偏差。
- 明日空间与连板推演假设指数持平。
